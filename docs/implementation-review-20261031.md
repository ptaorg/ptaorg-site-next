- 既存ガイドの実在URLに接続。文字サイズ・操作領域・主要色のコントラスト・フォーカスを改善。

## 発見し修正した問題

1. 390pxの見出しが「ら。」だけ次行になる問題：意味のまとまりで改行。
2. モバイル導入が長く入口を押し下げる問題：英語見出し・重複説明を小画面で省略。
3. ダイアログを素早く開き直すと旧closeイベントが新しい編集状態に干渉する問題：再表示中の旧close処理を抑止。
4. 静的索引生成時、隔離実行環境にURLがなく、学校リンクが汎用回答集へ置換される問題：実行環境を修正し、569校＋72回答を全件照合する回帰テストを追加。
5. 複数行のタイトルリンクで中央の空白がクリック対象にならない問題：リンクの矩形領域全体を押せるよう修正。
6. 小画面の目次が資料より前に大きな領域を占める問題：折りたたみ形式へ変更。
7. 研究ノートと回答索引の日付が異なる記録（川口市等）：原文の独立再照合が必要。本文・日付を推定で変更せず、同じ回答URLで日付が食い違う場合の注記を追加。
