# フッター改修とSNSロゴの出典
開発ブランチのフッターは既存サイトの連絡先・発信先・カテゴリー構成を継承し、応援の帯をオレンジ（#F28A3D）、本文を濃紺（#122B43）とする。

X・YouTube・noteは公式デザインと照合した形状のロゴを使い、Unicodeの擬似アイコンを撤去した。使用するローカルSVGのパスの取得元は **Simple Icons** である（公式サイトから直接ダウンロードした元ZIPではない）。商標権は各社に帰属する。

- Xの公式ブランドキット https://about.x.com/en/who-we-are/brand-toolkit
- YouTube公式ブランド情報 https://brand.youtube/
- note公式ロゴガイド https://www.help-note.com/hc/ja/articles/360000235582
- SVG参照元 https://github.com/simple-icons/simple-icons/tree/develop/icons

フッター内のX・YouTube・noteリンクは当委員会の既存公式発信先。掲載は各プラットフォームによる団体への後援・認定を意味しない。

開発用PRはドラフトのまま。本番サイト、CNAME、DNS、PDF公開範囲は変更しない。現行のB＋Cデザインの完全統合とは別作業で、承認された大きなヒーローと直下の検索欄を変更しない。
