# PTA適正化推進委員会 次世代サイト（開発中）

現行 https://ptaorg.com/ とは独立した検証用サイトです。**本番公開・ドメイン切替は未実施**。GitHub PR #3 `redesign/bc-public-data-20261108` をドラフトのまま維持します。

## 実装済み

- トップ、全国検索、自治体、学校、論考のレスポンシブ画面
- 日本語明朝のヒーローと、その下の独立した検索欄
- 実地形に基づく47都道府県のSVG地図（出典・利用条件は `docs/THIRD_PARTY_JAPAN_MAP.md`）
- 既存公開索引29地域・569校に、一宮市21校の公開原本索引を追加（計30地域・590校）。公開行政回答72件
- 現行公開サイトの論考31本を本文ごと移行。検索画面だけで分割全文索引6件を読み込む（失敗時はメタデータ検索）
- 従来の学校文書1,601件の**書誌・公開状態**を保持し、未公開原本を公開しない。一宮市の別途原本照合済み21校・42件は、原本のGoogle Drive直接URLを学校別に追加
- 個人情報保護委員会の2026年3月公表資料、61条・69条、学校側の所掌事務を解説する `guides.html` を追加。PPC17ページ逐ページ解説、一次資料の読み方、任意加入、教育委員会責任、学校管理、会費徴収、個人情報、教職員関与、学校施設利用、保護者向け説明など**17ページの主本文を新サイトに移行済み**。出典の元URL・Git blob SHAを固定して、画像・PDFは元の公開URLを参照。`data/fulltext-guides.json` に17ページの全文を索引化し、検索種別「解説」に接続（元のサイト固有の装飾・動作までは完全再現していない）
- 一宮市21校・42件の原本監査台帳 `data/ichinomiya-primary-review-20261109.json` とブラウザーで見られる `ichinomiya-review.html` を追加。学校別の原本ページ、確認した資料記載、学校側の権限未確認事項、個人情報の留保を区別し、学校・自治体ページから接続。原本42件全370ページの6面一覧による概観を終えたが、全個人情報の不存在判定ではない。
- 旧サイトに依存する公開ファイル92点を `data/public-asset-dependencies.json` に列挙。安全性を個別確認した装飾画像2点・自作説明図1点のみ元ファイルを変更せず移行。残り89点は移行しない。PDFは新サイト内に複製せず、元のDriveのURLだけ参照する

## 検証

```bash
npm test
python3 -m http.server 8765
# http://localhost:8765/
```

- `npm test` は公開索引、論考全31本、解説17ページの全文・出典記録、全文検索、既存導線、原本バイト同一性などを確認します。
- `tests/ichinomiya-primary-review.test.mjs` は21校42件370ページの監査範囲、原本URL・SHA、個人情報留保、根拠頁と学校別検証の関係を確認します。
- `tests/ichinomiya-originals.test.mjs` は、一宮市42件のSHA-256、合計370ページ／109,632,392バイト、21校の学校別導線を検査します。原本SHA-256台帳は現行サイトの `data/ichinomiya-original-pdf-sha256-20261109.json` を参照してください。
- `tests/asset-provenance.test.mjs` は、移行済み3点についてソースを固定したGit blob SHAとの一致を確認します。
- GitHub Actions の `Next site verification` と `Browser layout QA` がCIで追加検証します。
- 旧公開サイトの本文照合には固定コミット `a1deb9ff2580b37ac69bb56bef3089d73f82c75b` を使用します。説明は `docs/JOURNAL_MIGRATION.md` を参照してください。

## 公開前に必要な作業

1. 依存ファイル残り89点を、著作権・個人情報・公開範囲・SHA-256同一性の順に点検し、移行可否を個別決定する。
2. 一宮市21校・42件の原本PDF直接リンクは登録済み。PDFは原本まま参照し、ファイルの共有権限は変更しない。その他の一宮市・各務原市の未公開学校原本は公開可否を別途点検する。42件・全370ページについて6面ずつの画像一覧で概観し、役員くじ引き・妊娠除外申請・会費人数区分等の重要頁は個別拡大確認した。成人の役員名・教職員名等が残る資料があり、全項目の高解像度個人情報審査・公開適法性判定は未完了。
3. 学校別資料、行政回答、論考のリンクを全件照合し、モバイル・PCで実表示とアクセシビリティを確認する。
4. 本番公開手続き、SEO、移行先とリダイレクトは別途検証する。**このPRの作業中にマージ・公開しない**。

## 不変条件

- この新サイトのPRから現行サイト・CNAME・DNS・Google Driveの共有権限を変更しない。既存サイトの一宮市記事への原本URLとハッシュ台帳追加は、独立した現行サイトの更新として実施済み。
- 未公開資料のPDF原本を加工・黒塗り・再配布しない。
- 行政の一次資料、団体の分析、学校別資料の目録を混同せず、出典・確認済み事項・未確認事項を区別する。
- 学校内に保存された情報と、公開された索引・資料を混同しない。
