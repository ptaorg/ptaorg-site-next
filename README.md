# PTA適正化推進委員会 次世代サイト（開発中）

現行 https://ptaorg.com/ とは独立した検証用サイトです。**本番公開・ドメイン切替は未実施**。GitHub PR #3 `redesign/bc-public-data-20261108` をドラフトのまま維持します。

## 実装済み

- トップ、全国検索、自治体、学校、論考のレスポンシブ画面
- 日本語明朝のヒーローと、その下の独立した検索欄
- 実地形に基づく47都道府県のSVG地図（出典・利用条件は `docs/THIRD_PARTY_JAPAN_MAP.md`）
- 既存公開索引29地域・569校、独立して公開されている一宮市の論考索引1地域（計30地域）、公開行政回答72件
- 現行公開サイトの論考31本を本文ごと移行。検索画面だけで分割全文索引6件を読み込む（失敗時はメタデータ検索）
- 学校文書1,601件の**書誌・公開状態**を保持。PDF原本は未確認のまま新サイトで直接提供しない
- 旧サイトに依存する公開ファイル92点を `data/public-asset-dependencies.json` に列挙。安全性を個別確認した装飾画像2点・自作説明図1点のみ元ファイルを変更せず移行。残り89点は移行しない

## 検証

```bash
npm test
python3 -m http.server 8765
# http://localhost:8765/
```

- `npm test` は公開索引、論考全31本、出典記録、全文検索、既存導線、原本バイト同一性などを確認します。
- `tests/asset-provenance.test.mjs` は、移行済み3点についてソースを固定したGit blob SHAとの一致を確認します。
- GitHub Actions の `Next site verification` と `Browser layout QA` がCIで追加検証します。
- 旧公開サイトの本文照合には固定コミット `a1deb9ff2580b37ac69bb56bef3089d73f82c75b` を使用します。説明は `docs/JOURNAL_MIGRATION.md` を参照してください。

## 公開前に必要な作業

1. 依存ファイル残り89点を、著作権・個人情報・公開範囲・SHA-256同一性の順に点検し、移行可否を個別決定する。
2. 一宮市・各務原市の未公開学校原本は、根拠資料と公開可否が確認できるまで掲載しない。既存公開記事を原本PDFの代用としない。
3. 学校別資料、行政回答、論考のリンクを全件照合し、モバイル・PCで実表示とアクセシビリティを確認する。
4. 本番公開手続き、SEO、移行先とリダイレクトは別途検証する。**このPRの作業中にマージ・公開しない**。

## 不変条件

- `ptaorg/ptaorg.github.io`、`ptaorg.com`、CNAME、DNS、Google Driveの共有権限を変更しない。
- 未公開資料のPDF原本を加工・黒塗り・再配布しない。
